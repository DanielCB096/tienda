# Criterios de éxito

El piloto se evalúa con datos, no con impresiones. Cada métrica tiene fuente y meta.

## Métricas

| Métrica | Meta | Fuente |
|---|---|---|
| Ventas registradas en el sistema | ≥ 95 % de las ventas del periodo | Comparación con libreta/cierre |
| Cortes con diferencia $0.00 | ≥ 90 % | Historial de cortes |
| Diferencia acumulada de caja | ≤ $50 en 30 días | Suma de diferencias |
| Pérdida de datos | 0 eventos | Respaldos y reportes |
| Respaldo verificado | 100 % de los días | Inicio y bitácora |
| Copia semanal fuera del equipo | ≥ 4 | USB/fecha |
| Productos con stock negativo | 0 | Inventario |
| Anulaciones | ≤ 3 % de ventas y con motivo | Ventas y bitácora |
| Tickets en espera perdidos o duplicados | 0 | Lista y ventas |
| Incidentes S1 | 0 abiertos más de 4 horas | Registro |
| Incidentes S2 | 0 abiertos más de 1 día hábil | Registro |
| Usuarios capacitados y evaluados | 100 % | Lista de competencia |
| Recomendación del dueño | ≥ 4 de 5 | Entrevista final |
| Recomendación del personal | ≥ 4 de 5 en promedio | Entrevista final |

## Criterios cualitativos

- El cajero vende sin ayuda después de la primera semana.
- El dueño entiende y confía en el corte.
- El catálogo se mantiene sin ediciones manuales de stock.
- Los respaldos se hacen sin recordatorio del facilitador.
- El dueño puede explicar qué hacer ante una falla.

## Decisión al día 30

| Resultado | Decisión |
|---|---|
| Métricas cumplidas y dueño ≥ 4/5 | **Continuar** con propuesta comercial y testimonio |
| Métricas casi cumplidas, problemas acotados | **Extender 15 días** con plan de corrección |
| S1 repetidas, pérdida de datos o desconfianza | **Detener**, recuperar datos y documentar |
| La tienda no tiene tiempo o personal | **Detener** sin costo, con aprendizajes |

La decisión se firma en una carta simple con fecha y condiciones. No se renueva
automáticamente.

## Informe final

1. Resumen de 1 página con las métricas.
2. Incidentes y cómo se cerraron.
3. Cambios de catálogo y usuarios.
4. Opiniones literales del dueño y cajeros.
5. Riesgos abiertos y pendientes de campo.
6. Decisión y próximos pasos.
